# Jericho Jacolo Portfolio

Frontend-only personal portfolio inspired by modern engineer showcase sites.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- Canvas particle / aurora / glow effects
- English + Filipino (Tagalog) language toggle

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Content

Resume data lives in `src/data/portfolio.ts`. Copy is bilingual in `src/i18n/dictionaries.ts`. Resume PDF is served from `public/Jericho-Jacolo-Resume.pdf`.
